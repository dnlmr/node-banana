Node Banana is now a desktop app for Mac that keeps itself up to date (Windows coming soon), with an agent that builds workflows on your own Claude Code or Codex subscription, a library that keeps everything you generate, and every node rebuilt on one anatomy.

**Download:** [Mac · Apple Silicon](https://nodebanana.app/download/mac) (macOS 13 or later). **Windows: coming soon.** The x64 installer shipped with this release for a few hours and was withdrawn, slow and buggy; it returns in a later release. Bring your own provider keys: Node Banana calls the providers directly and their usage is billed to you by them.

## The desktop app

**Installable, signed, self-updating.** The Mac app is signed and notarised. It checks this repository's releases for updates (15 seconds after launch, every six hours, or Help → Check for Updates…), download on request and install on **Restart to update**.

**Your keys and your files stay yours.** Provider keys are encrypted in your OS profile (import them from a `.env` explicitly if you have one). Workflows and generated media are files in the Node Banana folder, Documents by default. The app's local server answers only its own window.

**It recovers.** Tabs, media and the graph come back after a crash, and the backend restarts without losing your work.

## Agent

Open the chat from the pill in the canvas's top-right corner. The agent creates workflows, edits the canvas and changes node settings through its own tools, and every turn runs on your **Claude Code** or **Codex (ChatGPT)** login through the vendor's CLI, never on API credits. It stops rather than spend extra usage. It works from your selection, remembers what you told it earlier in the conversation, queues messages you send while it works, and reads a prompting guide for the node and model before it writes a prompt. **Look up prompting tips** searches the web for a model's prompting advice and keeps the notes.

## Asset library

Everything you generate or edit is saved as it is made, with or without a project, and shown in the Assets view (press `A`): filters, favourites, tags, trash and restore, a full-screen detail with the run that produced each asset, and a jump to its workflow or project. Existing project folders are found and can be moved into the Node Banana folder from Settings → Library.

## Canvas

- **Nodes** are built from one anatomy: a media card that shows images, video, audio and text at their native proportions, sockets set into its border, and a controls card beneath with every setting. The side settings rail is gone.
- **Batch runs**: run a workflow or a group up to 50 times from the Run menu; each output says which run made it.
- **Saving**: Cmd/Ctrl+S saves, autosave follows your edits, and **Save automatically** can be turned off.
- **Noodles**: labels, hide-without-losing, bundles with a movable clamp, re-plug by dragging an end, marquee selection, appearance settings, and a comet along the noodles into a running node.
- **Arrange** menu with a live spacing slider; a navigator card; a floating menu and browser-style tabs; calmer groups; key caps in the shortcuts dialog.
- **Model browser** loads every provider's list once and filters locally; **Search Replicate and fal.ai** goes deeper.
- **Models**: GPT Image 2.5 with OpenAI's image controls, Gemini Omni video, current text-model lists, and the Comfy Router catalog brought up to date (FLUX 3 Image, Ideogram 4.5, Seedream 5.0 Flash, Eleven v4, Grok Imagine Video 1.5 Lite). One Comfy key in Settings → Providers serves Comfy Cloud and the Router.
- **Media**: a full-screen viewer for recent generations and the output gallery, hover-to-play video, a resizable gallery, and a Split Grid cell editor that builds a per-cell pipeline.
- **Selection**: a marquee takes a node once it holds the node's picture whole; the multi-select bar sits on the canvas and pans with the nodes.

## Security

The web build listens on 127.0.0.1 unless `HOST` says otherwise and refuses cross-site requests to its API; the Comfy key goes only to the configured engine; Next.js and the flagged dependencies are patched. The September audit and what landed from it are in `docs/codebase-audit.md`.

## Fixed

A workflow opened from a file could start at an empty corner of the canvas; agent calls that left optional arguments out were rejected; saves could keep a ref to a file that was not there, truncate the previous file on a failed write, or land on the wrong canvas; a stopped run could overwrite the next; uploads could land on the wrong node; a string setting like `video_size` showed up as a video input (#135); and more in the [changelog](https://github.com/shrimbly/node-banana/blob/master/CHANGELOG.md).

## Verify a download

Each release lists `SHA256SUMS-mac-arm64.txt`; compare with `shasum -a 256 <file>`.
